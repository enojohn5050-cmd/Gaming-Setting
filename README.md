## 📌 About The Project

This project is a frontend practice project created to improve my understanding of **HTML, CSS, responsive design, and basic JavaScript functionality**.

## 💡 How It Works

Users can select the settings they want and save their preferences.

The project uses **localStorage** to keep saved settings in the browser, so the selected preferences can remain after refreshing the page.

The **Reset** button clears the saved settings and returns all options to their default state.
